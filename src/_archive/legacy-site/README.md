# Archived portfolio

The former homepage and its 21 themed presentations were retired in favour of Operation: Pineapple. This is a source snapshot, not a live Astro route directory. Data and site metadata are included to preserve the original relative imports.

The active biography remains in `src/data/resume.ts`. Static assets in `public/assets` are retained. To experiment with an old theme, copy it into a separate Astro project with these supporting directories; do not restore the whole archive into the active pages directory.
